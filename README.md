# No-Spoiler NBA Schedule
A free, mobile-first NBA schedule app that hides game scores by default — built for fans who watch games on delay.
nospoilnba.vercel.app | Built with Next.js, React, Tailwind CSS

## Why I Built This
I watch NBA games on League Pass a few hours or days after they air so I can skip the timeouts. The problem: every time I'd Google a game time or schedule, the score was right there in the results. Spoiled.
Every existing schedule app defaults to showing scores. None of them had a spoiler-free mode. So I built one.
Key Features

## Scores hidden by default — reveal them on your own terms
Direct links to watch each game on NBA.com
Date menu and controls to jump to specific days or months
Pulls live schedule data directly from NBA.com's JSON feed
Fully responsive, mobile-first design

## How It Was Built
The app reads from NBA.com's publicly available JSON schedule file to display each day's games in real time. Scores are hidden by default and can be toggled per game. Built with Next.js, React, and Tailwind CSS and deployed on Vercel.

## Tech Stack
Next.js, React, Tailwind CSS, NBA.com JSON, deployed on Vercel
